# Product Overview

ngopidulur-astro is a personal blog/portfolio website built on the Frosti theme (v3.3.3) for Astro. It is a static site that features:

- Blog with posts written in Markdown/MDX
- Category and tag taxonomy for blog posts
- Full-text search powered by Pagefind
- Project showcase page
- Friend links page
- About page
- RSS feed and sitemap generation
- Dark/light theme toggle (DaisyUI themes: winter/dracula)
- i18n support via YAML translation files
- OG image generation with Satori
- Math rendering with KaTeX
- Expressive code blocks with syntax highlighting

The site is configured primarily through `frosti.config.yaml` (site metadata, menus, user info, social links) and `src/i18n/translations.yaml` (UI text translations).
