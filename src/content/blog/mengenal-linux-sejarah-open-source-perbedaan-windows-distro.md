**Linux** — sistem operasi yang kini menggerakkan 80% dari 500 superkomputer teratas dunia, seluruh smartphone Android, dan mayoritas server internet. Tapi Linux bukan sekadar OS; ia adalah filosofi, komunitas, dan revolusi teknologi.

Artikel ini membawa kamu mengenal Linux dari akarnya.

## Sejarah Linux

### Awal Mula: Proyek Hobi Seorang Mahasiswa

Tahun 1991, **Linus Torvalds** — mahasiswa Universitas Helsinki, Finlandia — memulai proyek hobi: membuat sistem operasi sendiri. Ia terinspirasi dari **MINIX**, sistem UNIX kecil buatan Andrew Tanenbaum untuk tujuan edukasi.

- **Agustus 1991**: Linux versi 0.01 selesai dikerjakan
- **5 Oktober 1991**: Linus mengumumkan versi 0.02 — hanya bisa menjalankan Bash shell dan GCC compiler
- **Sekarang**: Linux adalah sistem UNIX paling lengkap, digunakan untuk server, jaringan, pengembangan software, dan desktop

### Kenapa Dinamakan "Linux"?

Nama Linux berasal dari kombinasi **Linus** + **Unix**. Awalnya Linus ingin menamainya "Freax" (Free + Freak + Unix), tapi administrator FTP server tempat kodenya diunggah mengganti folder menjadi "Linux" — dan nama itu bertahan hingga sekarang.

## Cerita di Balik Logo TUX si Penguin

Kenapa logo Linux adalah **penguin**? Bukan singa atau harimau yang lebih "sangar"?

Ceritanya: saat berlibur di Australia, Linus Torvalds **digigit seekor penguin kecil** sampai demam berhari-hari. Alih-alih trauma, Linus justru terinspirasi — ia ingin "demam Linux" mewabah seperti demamnya setelah digigit penguin.

Nama **TUX** adalah akronim dari:
- **T**orvalds
- **U**ni**X**

Dan James Hughes adalah orang yang memberi nama tersebut. Karakter TUX didesain oleh seniman **Larry Ewing**, dan kini menjadi trademark resmi Linux.

## Apa Itu Open Source?

Linux didistribusikan di bawah lisensi **GNU General Public License (GPL)**. Artinya:

1. **Bebas digunakan** — untuk tujuan apa pun
2. **Bebas dipelajari** — kode sumber tersedia
3. **Bebas dimodifikasi** — bisa disesuaikan dengan kebutuhan
4. **Bebas didistribusikan ulang** — bahkan kamu bisa membuat distro sendiri

> Open source = kode sumber bisa dilihat, dipelajari, diubah, dan dibagikan oleh siapa pun.

## Perbandingan Linux vs Windows

| Aspek | Linux | Windows |
|-------|-------|---------|
| **Harga** | Gratis (mayoritas distro) | $50-$150 per lisensi |
| **Kemudahan** | Perlu belajar terminal | Lebih familiar untuk pemula |
| **Kehandalan** | Bisa berbulan-bulan tanpa reboot | Perlu reboot berkala |
| **Software** | Banyak alternatif open source | Lebih banyak aplikasi komersial |
| **Harga Software** | Mayoritas gratis | $20-$200 per aplikasi |
| **Hardware** | Dukungan makin luas | Hampir semua hardware support |
| **Keamanan** | Sangat aman, sedikit malware | Rentan virus & malware |

> Linux lebih aman bukan karena "tidak ada yang membuat virus untuk Linux", tapi karena arsitektur keamanannya yang lebih ketat: permission system, user isolation, dan open source auditing.

## Multi-User & Multi-Tasking

Linux adalah sistem operasi **multi-user** dan **multi-tasking**:

- **Multi-user**: Ratusan user bisa login bersamaan, masing-masing dengan environment terpisah
- **Multi-tasking**: Menjalankan banyak program secara bersamaan

Ini menjadikan Linux ideal sebagai **server** — satu mesin melayani puluhan hingga ribuan user sekaligus.

## Distro Linux Populer

Distro (distribusi) Linux adalah "paket lengkap" — kernel + aplikasi + package manager + konfigurasi.

### Distro Tertua & Paling Berpengaruh

| Distro | Karakteristik | Package | Turunan Terkenal |
|--------|--------------|---------|------------------|
| **Red Hat** | Populer, mudah instalasi | `.rpm` | Fedora, CentOS |
| **Debian** | Stabil, handal | `.deb` | Ubuntu, Kali Linux |
| **Slackware** | Paling "murni", untuk advanced user | `.tgz` | - |
| **SuSE** | Terkenal dengan YaST (config tool) | `.rpm` | openSUSE |
| **Mandrake** | Optimasi untuk Pentium | `.rpm` | Mandriva |

### Ubuntu: Distro Paling Populer

Ubuntu adalah turunan Debian yang fokus pada **kemudahan penggunaan**. Inilah distro yang paling direkomendasikan untuk pemula.

### Kali Linux: Distro untuk Security

Berasal dari BackTrack, Kali Linux adalah distro Debian-based untuk penetration testing dan keamanan jaringan.

## Kelebihan Linux (Ringkasan)

1. **Gratis** — tidak perlu lisensi
2. **Open source** — kode bisa dipelajari
3. **Aman** — arsitektur keamanan tangguh
4. **Ringan** — bisa jalan di hardware lama
5. **Stabil** — jarang crash atau perlu reboot
6. **Komunitas global** — bantuan selalu tersedia
7. **Bisa dimodifikasi** — buat distro sendiri
8. **Live CD/USB** — coba tanpa install
9. **Kompatibilitas** — baca 100+ filesystem
10. **Multi-platform** — x86, ARM, 32-bit, 64-bit

## Kesimpulan

Linux lebih dari sekadar sistem operasi — ia adalah gerakan teknologi yang mendemokratisasi akses ke komputasi berkualitas. Dari server web hingga smartphone, dari superkomputer hingga Raspberry Pi, Linux ada di mana-mana.
