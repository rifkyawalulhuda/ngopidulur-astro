## Use Cases untuk Fresh Graduate dan Job Seeker

### #42 — Simulasi Wawancara Kerja
```
"Dengan mengambil peran sebagai pewawancara, berikan saya daftar
pertanyaan untuk posisi [masukkan posisi] di industri [masukkan sektor].
Sertakan ruang untuk saya memberikan jawaban. Setelah saya menjawab,
berikan feedback tentang respons saya."
```
**Manfaat:** Persiapan wawancara yang realistis tanpa tekanan.

### #43 — Optimasi Profil LinkedIn
```
"Bisakah kamu memberikan langkah-langkah yang dapat ditindaklanjuti
untuk membuat profil LinkedIn saya lebih menarik dan unik?
Sajikan langkah-langkah ini dalam format tabel, dan sertakan juga
saran tentang cara efektif memperluas jaringan di platform ini."
```

**Tips LinkedIn dari panduan:**

| Bagian | Yang Harus Dilakukan |
|--------|---------------------|
| Headline | Gunakan keyword industri, bukan hanya jabatan |
| About | Ceritakan nilai unik yang kamu tawarkan |
| Experience | Kuantifikasi pencapaian (angka, persentase) |
| Skills | Minimal 5 skill relevan, minta endorsement |
| Recommendations | Minta rekomendasi dari mantan rekan/atasan |

### #44 — Negosiasi Gaji
```
"Bisakah kamu memberikan tips dan strategi untuk bernegosiasi gaji
secara efektif saat mendaftar pekerjaan? Berikan panduan langkah demi
langkah dan poin-poin kunci yang perlu diingat. Selain itu, berikan
contoh cara merespons berbagai situasi negosiasi."
```

**Kerangka negosiasi yang efektif:**
1. Riset kisaran gaji pasar untuk posisi serupa
2. Tentukan angka minimum yang bisa diterima
3. Mulai dengan angka lebih tinggi dari target
4. Dukung dengan data pencapaian konkret
5. Pertimbangkan benefit non-gaji (training, jadwal fleksibel)

### #45 — Adaptasi di Lingkungan Kerja Baru
```
"Bisakah kamu membantu saya menilai seberapa baik saya beradaptasi
dengan lingkungan kerja baru? Berikan sistem tes untuk mengevaluasi
tingkat adaptasi saya saat ini, beserta interpretasi hasil. Selain itu,
sarankan strategi untuk meningkatkan kemampuan adaptasi saya."
```

### #46 — Evaluasi Kemampuan Komunikasi
```
"Bisakah kamu membantu saya mengevaluasi kemampuan komunikasi

beserta interpretasi hasil."
```

### #47 — Menampilkan Keahlian di Tempat Kerja Baru
```
"Sebagai karyawan baru di perusahaan, bagaimana saya bisa secara

dan atasan? Berikan langkah-langkah konkret untuk menampilkan keahlian
dan menonjolkan kekuatan di tempat kerja."
```

### #48 — Memahami Budaya Perusahaan
```
"Sebagai karyawan baru, saya ingin memahami budaya kerja perusahaan.
Bisakah kamu menjelaskan cara menggunakan Competing Values Framework
untuk menilai budaya kerja dan memberikan saran cara bernavigasi
secara efektif?"
```

**Competing Values Framework — 4 kuadran budaya:**

| Kuadran | Karakteristik | Cara Bertindak |
|---------|--------------|----------------|
| **Collaborate** | Kekeluargaan, teamwork | Bangun hubungan, dukung tim |
| **Create** | Inovasi, eksperimen | Ajukan ide baru, ambil risiko |
| **Compete** | Hasil, target, kompetisi | Fokus pada KPI, tunjukkan angka |
| **Control** | Proses, stabilitas, efisiensi | Ikuti prosedur, dokumentasikan |

```
atau best practices industri."
```

### #53 — Gelar vs Pengalaman Kerja (SWOT)
```
"Saya mencoba memutuskan antara melanjutkan gelar [masukkan gelar]
atau mendapatkan lebih banyak pengalaman kerja praktis [masukkan industri].
Bisakah kamu membuat analisis SWOT untuk membantu keputusan ini?"
```

**Template SWOT yang bisa diminta:**

| | Lanjut Kuliah | Langsung Kerja |
|--|---------------|----------------|
| **Strength** | Gelar formal, network akademis | Pengalaman nyata, income |
| **Weakness** | Biaya, waktu | Tanpa gelar untuk posisi tertentu |
| **Opportunity** | Research, karir akademis | Naik jabatan lebih cepat |
| **Threat** | Market jenuh dengan sarjana | Ketinggalan update akademis |

### #66 — Feynman Method untuk Belajar
```
"Saya ingin belajar lebih banyak tentang [Subjek Minat], dan saya
mendengar tentang metode belajar Feynman. Bisakah kamu memberikan
langkah-langkah konkret dan contoh cara menerapkan metode Feynman
untuk mempelajari subjek ini?"
```

**Feynman Method — 4 langkah:**
1. **Pilih konsep** yang ingin dipahami
2. **Jelaskan dengan kata sederhana** — seolah menjelaskan ke anak kecil
3. **Identifikasi gap** — bagian mana yang tidak bisa dijelaskan dengan jelas?
4. **Review dan sederhanakan** — kembali ke sumber, perbaiki penjelasan

## Midjourney: Generative AI untuk Gambar

**Midjourney** adalah generator gambar AI yang mirip dengan DALL-E dari OpenAI. Ia menghasilkan gambar berdasarkan deskripsi teks yang diberikan pengguna.

Platform ini telah digunakan oleh berbagai acara TV, jurnal, surat kabar, dan institusi.

### Cara Kerja Prompt Midjourney

```
[deskripsi gambar] --ar [aspect ratio] --v [versi] --s [stylize] --q [quality]
```

**Parameter Penting:**

| Parameter | Fungsi | Contoh |
|-----------|--------|--------|
| `--ar` | Aspect ratio | `--ar 4:3`, `--ar 16:9`, `--ar 2:3` |
| `--v` | Versi model | `--v 5`, `--v 6` |
| `--s` | Stylize (estetika) | `--s 250` (rendah) hingga `--s 1000` (tinggi) |
| `--q` | Quality | `--q 1` (cepat) atau `--q 2` (detail) |
| `--upbeta` | Upscale beta | Untuk resolusi lebih tinggi |

### Contoh Prompt Midjourney dari Panduan

**Foto Kuda Galaksi:**
```
galaxies, spirals, space, nebulae, stars, iridescent, intricate detail,
in the shape of a horse, octane render, 8k, --q 2 --ar 2:3 --uplight
```

**Foto Elang Menangkap Ikan:**
```
Beautiful falcon catching a fish, cinematic lighting --ar 4:3 --upbeta
```

**Kapal di Laut Badai:**
```
A real photographic landscape painting with incomparable reality,
Ominous sky, Sailing boat, Lotus, Huge waves, Starry night,
Volumetric lighting, Clearing, Realistic, artstation --ar 4:3
```

**Atlantis Bawah Air:**
```
Atlantis under the water photo should be 8K --ar 4:3 --v 5 --s 250
```

### Tips Prompt Midjourney yang Efektif

1. **Deskripsikan gaya** — "cinematic", "photorealistic", "8K", "oil painting"
2. **Tentukan pencahayaan** — "golden hour", "dramatic lighting", "soft ambient"
3. **Sebutkan kamera/lensa** — "shot on 50mm lens", "wide angle", "macro"
4. **Gunakan referensi seniman** — "in the style of [artist]", "artstation"
5. **Spesifikasikan mood** — "ominous", "serene", "chaotic", "ethereal"



## Ringkasan

30 prompt dalam artikel ini mencakup semua fase karir — dari fresh graduate yang mempersiapkan wawancara, karyawan baru yang beradaptasi dengan lingkungan kerja, hingga profesional berpengalaman yang ingin meningkatkan produktivitas.

**Kunci penggunaan efektif:**
- Isi bagian `[dalam kurung]` dengan detail spesifik situasimu
- Minta format output (tabel, poin, langkah-langkah) untuk hasil terstruktur
- Iterasi dan perbaiki prompt berdasarkan output pertama
